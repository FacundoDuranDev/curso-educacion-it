# 📖 GETTING STARTED - TUTORIALES PASO A PASO

## 🎯 **OBJETIVO DE ESTA SECCIÓN**

**Aprende desde cero** con tutoriales diseñados para llevarte desde la instalación hasta tu primer proyecto funcionando.

---

## 📚 **TUTORIALES DISPONIBLES**

### **🚀 [instalacion-rapida.md](./instalacion-rapida.md)**
> **⏱️ 15 minutos** | **👤 Principiante**

Tu primera experiencia con el entorno. En 15 minutos tendrás todo funcionando.

**Lo que aprenderás:**
- ✅ Instalar Docker y dependencias
- ✅ Levantar PostgreSQL
- ✅ Verificar que todo funciona
- ✅ Acceder a las interfaces web

### **🎯 [primer-uso.md](./primer-uso.md)**
> **⏱️ 30 minutos** | **👤 Principiante**

Tu primera experiencia práctica con el sistema completo.

**Lo que aprenderás:**
- ✅ Conectar a PostgreSQL
- ✅ Cargar datos de ejemplo
- ✅ Ejecutar tu primera consulta
- ✅ Acceder a Jupyter

### **🏗️ [configuracion-completa.md](./configuracion-completa.md)**
> **⏱️ 60 minutos** | **👤 Intermedio**

Configuración completa del entorno con Hadoop, Hive y Spark.

**Lo que aprenderás:**
- ✅ Levantar el clúster completo
- ✅ Configurar Hive
- ✅ Configurar HDFS
- ✅ Ejecutar jobs de Spark
